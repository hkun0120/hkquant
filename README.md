## 当前研究结论

2018—2022年聚宽策略库已完成495份范围筛选、233份重点标题池和56份结构化深审。A股真实复权ETF与严格回测底座已完成。当前“风险资产趋势选择＋国债ETF防御腿”严格运行210002在2020-01-02至2022-12-30的总收益为22.2221%、年化收益7.2034%、最大回撤-7.5730%；它只是低回撤候选，不应作为香港量化比赛的主收益引擎。

A股质量价值点时点初测严格运行180002总收益为-3.0908%、最大回撤-26.4578%；ETF动量—RSRS扩展参数测试显示规则对参数和市场阶段敏感。高收益高回撤收益源、最终高收益低回撤复合组合、美股和港股同口径验证仍未完成。

## 继续顺序

第一步验证股票截面动量、小市值/成长、ATR或多资产趋势等高收益来源；第二步对A股质量价值扩展更长区间、季度更新、行业中性、退市和流动性约束；第三步把已经完成的防御性ETF趋势作为风险控制腿，而不是收益引擎；第四步在独立训练/测试区间做组合相关性、边际风险贡献、成本和回撤压力测试。

## 外部数据限制

当前Tushare账户对 `us_daily` 和 `us_fina_indicator` 的AAPL样本探测返回无访问权限，不能在没有权限或合法CSV/Parquet的情况下启动美股回测。港股 `hk_daily` 曾触发每小时频率限制，自动回填任务保留原数据源原则；在任务成功前不能捏造港股结果，也不能静默替换数据源。

## 安全边界

不要在代码、报告、日志、前端、数据库元数据或交接包中写入服务端Tushare令牌。运行时凭证应通过目标环境的受保护环境变量注入。压缩包已排除 `.env`、日志、node_modules、`.git` 和本地运行缓存。
